## Review Focus

1. **Phone width (360 px):** dense charts (13 years of Voyager data with 4 markers, 3-cycle energy chart), two-ball bounce lab and wide tables must not scroll the page horizontally or overlap labels. Each topic's e2e spec asserts `document.documentElement.scrollWidth <= 360` and that every `DataTable` region scrolls internally.
2. **Degenerate inputs:** e = 0 (ball sticks), e = 1 (T = ∞), e = 1,2 (energy grows), η = 0 or P_máx = 0 (no regen; % readout 0, no NaN), r_p at the planet radius, T below T_min. Each kernel task carries a test that the function returns finite or explicit `Infinity` values and each lab task a test that readouts never render `NaN` and the scene never leaves the canvas (clamp + warning text).
3. **Dark theme:** new diagram and chart colors read correctly in `data-theme="dark"`; covered by axe in both themes and by `tokens.test.ts` contrast checks; static SVG diagrams use `var(--token)`, never hex.
4. **Keyboard-only use:** every draggable handle (wheel target angle, flyby r_p, energy cursor, bounce h₀) has a slider or arrow-key alternative; each lab test drives one handle with the keyboard and asserts a readout change.
5. **Reduced motion:** with `motion: reduced` the bounce, flyby, wheel and drive-cycle animations advance in discrete steps; each lab test sets the global setting and asserts no continuous `requestAnimationFrame` loop (follow `HabitatLab.test.tsx`).
